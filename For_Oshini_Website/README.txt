FOR OSHINI ❤️ — FROM KITHSARA

HOW TO OPEN
1. Download and extract this ZIP.
2. Open the For_Oshini_Website folder.
3. Double-click index.html to open it in a browser.

FEATURES
- Floating heart animations and a surprise love note
- Background music: an original soft melody generated by the website
- Heart Catcher mini-game
- Pick-a-flower message surprise
- Match-the-pairs memory game
- A three-question mini quiz
- Responsive layout for phones and computers

MUSIC
Tap the "Play music" button in the top-right area. Browsers require a tap before audio can start. The melody is generated in the browser; no music file is needed.

CUSTOMIZE
- Edit index.html for names and messages.
- Edit style.css for colors and layout.
- Edit script.js for games, quiz questions, and music behavior.

Google Fonts need an internet connection; the website otherwise works offline.
